# Bahasa Melayu (Malaysia) Copy Guide

Use this whenever output is in Bahasa Melayu for a Malaysian audience. It applies to `copywriting`, `ad-creative`, `social`, `sms` (WhatsApp) and `copy-editing`.

## 1. Write Malaysian BM, not Indonesian
AI often leaks Indonesian words. Malaysians notice immediately and it feels "tak lokal". Always swap:

| ❌ Indonesian / awkward | ✅ Malaysian BM |
|---|---|
| desain, didesain | reka bentuk, direka |
| dirancang khusus | direka khas |
| Anda temukan / menemukan | anda temui / jumpa |
| kualitas | kualiti |
| material | bahan / fabrik |
| pengrajin | tukang / artisan |
| mewah banget | sangat mewah / mewah gila (casual) |
| silakan | sila / jom |
| gratis | percuma |
| belanja (as in spend) | ok in both — but "beli-belah" for shopping |
| ukuran | saiz |
| handuk | tuala |
| bantal guling | bantal peluk |
| kasur | tilam |

Lowercase *anda* mid-sentence is standard in Malaysia. *Anda* is formal, so in casual copy prefer *korang* (very casual), *awak*, or drop the pronoun entirely.

## 2. Two registers (pick per asset)

**Polished (brand assets: website, headlines, catalogues, B2B decks)**
- Standard BM, complete sentences, no slang.
- E.g. *"Nikmati keselesaan tidur setaraf hotel 5 bintang, setiap malam."*

**Relaxed-premium (social, TikTok, ad hooks, WhatsApp replies)**
- Conversational, light English mixing is fine where Malaysians naturally say it (e.g. *set*, *custom*, *premium*, *comfy*).
- Still premium, so no heavy slang, no ALL CAPS shouting and no 🔥🔥🔥 spam.
- E.g. *"Tidur macam kat hotel 5 bintang, tapi kat rumah sendiri."*
- E.g. *"Pilih warna. Pilih fabrik. Siap — cadar yang memang 'awak'."*

Never mix both registers in one sentence.

## 3. Premium voice in BM (Apple-style)
- Short lines. Full stops for rhythm: *"Lembut. Sejuk. Tahan lama."*
- Sensory verbs: *rasa, sentuh, baring, lena, hanyut*.
- Confident, not desperate. Avoid *"JANGAN LEPASKAN PELUANG!!!"*, *"murah gila"*, *"stok terhad cepat!!"*.
- Light playfulness is fine: *"Amaran: susah nak bangun pagi."*
- Show, don't claim. Instead of *"kualiti terbaik"*, describe what it feels like: *"rasa sejuk bila baring, lembut bila dipeluk."*

## 4. Meta ad text limits (FB/IG)
| Field | Limit before truncation | Tip |
|---|---|---|
| Primary text | ~125 characters visible | Hook in the first line; BM runs longer than English, so keep it tight |
| Headline | ~27–40 characters | One benefit, polished register |
| Description | ~25–30 characters | Often hidden, so don't rely on it |
| CTA button | "Send WhatsApp message" / "Hantar Mesej WhatsApp" | Match the Click-to-WhatsApp objective |

## 5. Malaysian context
- Currency: `RM119`, `dari RM119`. Never "RM 119.00" in ads.
- Key seasons: Hari Raya Aidilfitri (biggest sales season for home goods), Aidiladha, Merdeka (31 Ogos), Hari Malaysia (16 Sept), 11.11, 12.12, school holidays, wedding season, payday (*gaji*, 25th onwards).
- Raya bedding refresh (*"cadar baru untuk raya"*) is a strong cultural hook.
- Be respectful of religious and cultural sensitivities. No bedroom imagery or copy that is suggestive.

## 6. BM AI-tells to avoid
- *"Bukan sekadar cadar, tetapi..."* (the BM version of "it's not X, it's Y")
- *"Dalam dunia yang serba pantas ini..."*
- *"Tingkatkan pengalaman tidur anda ke tahap seterusnya"*
- Stacked adjectives: *"premium, eksklusif, mewah dan berkualiti tinggi"*. Pick one and prove it.
- Over-formal translation-sounding phrasing, such as *"Adakah anda sedang mencari..."*
