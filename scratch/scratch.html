Electronics parts Sensors

HC-SR04 ultrasonic sensor

Measures 2–400 cm with a sound ping. Cheap and reliable indoors; blind under 2 cm and on soft surfaces.

Sensor5V · 15 mANo libraryRM5–10
ECHO outputs 5V. On ESP32, put a 1k/2k voltage divider between ECHO and the GPIO.

How it works

A 10 µs pulse on TRIG fires eight 40 kHz pings. ECHO then goes HIGH until the sound bounces back, so the HIGH time is the round trip. Divide the microseconds by 58 to get centimetres.

Pins

PinModeVoltageNote
VCCPower5VFrom VIN, not 3V3
TRIGOutput3.3V ok10 µs pulse starts a ping
ECHOInput5VNeeds divider on 3.3V boards
GNDGround—Share ground with the board

Wiring on ESP32

  1. 1VCC → VIN (5V from USB) and GND → GND.
  2. 2TRIG → GPIO 19. 3.3V is enough to trigger it.
  3. 3ECHO → 1 kΩ → GPIO 18, then GPIO 18 → 2 kΩ → GND. That turns 5V into a safe 3.3V.
snippets/sensors/hc-sr04-read
#include "pins.h"

const unsigned long PING_EVERY_MS = 60;
unsigned long lastPing = 0;
float distanceCm = -1;            // -1 = no echo yet

void setupSonar() {
  pinMode(SONAR_TRIG, OUTPUT);
  pinMode(SONAR_ECHO, INPUT);         // through the 1k/2k divider
}

void updateSonar() {                // call every loop(), never blocks long
  if (millis() - lastPing < PING_EVERY_MS) return;
  lastPing = millis();
  digitalWrite(SONAR_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(SONAR_TRIG, LOW);
  unsigned long us = pulseIn(SONAR_ECHO, HIGH, 25000);  // 25 ms timeout
  distanceCm = us ? us / 58.0 : -1;
}

Common problems

Always reads -1 or 0ECHO isn't reaching the pin. Check the divider and that GND is shared, then raise the timeout to 30 ms.
Numbers jump aroundTake three readings and use the middle one. Keep it 5 cm or more from the chassis edge.
Misses soft or angled objectsSound gets absorbed or bounces away. Aim it straight, or add an IR sensor for close range.
