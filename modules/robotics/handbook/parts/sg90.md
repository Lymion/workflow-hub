# SG90 micro servo

9 g servo, 0–180°. Send a 50 Hz pulse of 0.5–2.4 ms to set the angle.

## Wiring
- Brown = GND, red = 5V, orange = signal.
- Power it from 5V (not the ESP32's 3V3 pin) and share ground.

## Code
Use the `ESP32Servo` library: `servo.attach(SERVO_SIGNAL); servo.write(90);`
